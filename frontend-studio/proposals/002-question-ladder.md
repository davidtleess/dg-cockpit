## Phase and season shifts

- **Contending flips 5–6 upward** (acquisitions and consolidation over stashing) and inverts pick
  doctrine: package capital into earlier picks/players. The architecture must let the default
  experience re-weight when posture changes — posture is already in the masthead.
- **In-season adds the Tuesday loop to #3–4:** last week's production bar vs. the model expectation
  line becomes the daily question; usage lenses (Week-3 concept) activate as data accrues.
- **Documented strategist disagreement to design around:** pick-volume doctrine (PFF: "more shots")
  vs. hoarding traps (Dynasty Nerds: capacity limits, picks-over-proven-talent failure mode). The
  app should present pick count against roster capacity descriptively, never resolve the debate.

## The juxtaposition rule (applies to every module above)

Every surface is built in the market's familiar structure; DG's model appears as the second lane
*inside* that structure — model rank beside market rank, expectation line on the standard value
graph, divergence highlighted where lanes disagree. Our insight is only legible inside the frame
users already know.
