Technique notes

grid 0fr→1fr ✓ default

A one-line grid track animates from 0fr to 1fr; the inner wrapper is min-height:0; overflow:hidden. Animates unknown height with no JS measuring, works in every current browser, and reverses cleanly mid-flight.

height:auto ◐ progressive

The native answer: interpolate-size:allow-keywords lets height transition to auto. Cleanest code, but Chrome/Edge 129+ only — Safari/Firefox snap (still functional). Enhancement, not a foundation.

max-height ✗ avoid

The common shortcut, and wrong: you guess a ceiling (520px) the real content never reaches, so the easing burns its curve on empty space — the open stalls early, the close hangs before it visibly moves. Flip to it at 4× and the dead time is obvious.

Choreography & easing

Height alone is a curtain lifting on a pre-drawn card. The columns instead fade + rise, staggered (left at 90ms, right at 150ms) so content reads as arriving. Open decelerates into rest (cubic-bezier(.16,1,.3,1)); close is quicker and accelerates away. On close the stagger is dropped — reverse-staggering looks like a stutter.

The floor

Rows are real buttons: Tab to focus, Enter/Space to open, visible focus ring. prefers-reduced-motion snaps everything to the final state — the simulate control shows exactly that.

The recipe — reusable
/* wrapper always in the DOM, collapsed */
.exp {
  display:grid; grid-template-rows:0fr;
  transition:grid-template-rows
    240ms cubic-bezier(.4,0,1,1);
}
.row.open + .exp {
  grid-template-rows:1fr;
  transition:grid-template-rows
    340ms cubic-bezier(.16,1,.3,1);
}
.exp-inner { min-height:0; overflow:hidden; }
