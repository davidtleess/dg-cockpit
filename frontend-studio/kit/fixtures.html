studio-kit fixtures

Every specimen below carries data-expect="pass" or data-expect="fail" for a named check. kit/verify.mjs asserts the checker returns exactly that verdict — in both directions. A checker that cannot reproduce a known-bad as bad is an opinion generator, which is what the density gate turned out to be on 2026-07-28 when it scored an approved surface worse than a rejected one, and again the same night when it silently stopped counting marks that gained a gradient and reported a false pass.

HIT / pass — kit marks

Small visual marks with the kit's expanded ::after target. Countability preserved, WCAG 2.5.8 met.

HIT / fail — hand-rolled marks

The same marks written by hand, the way every Studio surface before the kit wrote them. 13×16px, no expanded target.

SEMANTICS / pass — every mark says what it is

Marks bound with tip() carry an accessible name built from the same strings the tooltip shows. A screen reader and a mouse reader get the same facts.

SEMANTICS / fail — pressable, and meaningless

The same marks with a hit target but no accessible name. hit would clear these; this is a different sense and must convict them.

CENSUS / pass — marks stay countable when they carry a gradient

The exact regression that produced a false pass: adding a gradient must not make a mark invisible to the counter.

CHROME / pass — constant-width bands are not data

Three season bands of identical width plus three real marks. A checker must count 3 data marks, not 6.

TYPE / pass — content on the product's scale, labels at the floor

A 13px micro-label is legitimate; 13px is the product's own smallest step.

roster moves a season
29.5

TYPE / fail — content below the floor

Content, not a label, at 11px. This is the 009-matrix conviction: 192 numbers set at label size.

Derrick Henry moved to Florida Man for a 2026 2nd

LEGEND / fail — a key the reader must re-apply

Okabe & Ito: label on the graphic. A legend forces a hue match, the channel that fails.

■ ours ■ market ■ gap ■ you

LEGEND / pass — identity direct-labelled once

The dumbbell names its two lanes on the mark itself the first time it appears.

ours 30th · market 64th

VOCAB / pass — kit surfaces

Flat fills, the product's radii, no elevation shadow. Hatch patterns are allowed: they encode missing data.

a surface

VOCAB / fail — the atmosphere pass

A gradient surface with elevation and a 10px radius, against a product that renders zero of either.

a surface that does not belong to this product
