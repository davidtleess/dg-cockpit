Depth, hierarchy, and the line where each technique starts lying.

Every pair below is the same content twice. Left is how Studio has been building — flat, hairline, monochrome. Right applies one named technique from products that read as premium.

The point is not that the right column is prettier. It is the boundary: each technique is craft on the room and a defect on a data mark, and the last section builds the defective version on purpose so the difference is visible rather than asserted.

Technique 01Elevation is a lightness step, not a shadow

A shadow is invisible on a dark surface, so depth has to come from luminance: 4–8% lightness per layer, four or five layers total. Studio's surfaces use two.

Technique 06Six states, not two

Default, hover, focus (keyboard), active, disabled, loading. Tab into these — the focus ring is a distinct state from hover, which is the one Studio keeps collapsing.

"Crafted microstates" — the invariant across Stripe/Linear/Vercel.

two states

Hover only. Keyboard focus borrows the hover look, so a keyboard user cannot tell where they are.

all six

Press and hold for active; Tab for the focus ring; the loading state keeps its width so the row cannot reflow.

Technique 07A spring is a different statement from a curve

Same distance, same duration. The cubic-bezier arrives and stops; the spring overshoots ~1.8% and settles, which reads as physical. Overshoot is legitimate on chrome and never on a mark whose position encodes a value.

The boundaryThe same techniques, on a data mark, are defects

This is the part worth keeping. Each technique above adds a visual channel. On the room that channel carries depth, which is free. On a mark it collides with the quantity the mark already encodes — so the reader is given two signals and one number.

The rule this lab produced, in one line

Light the room, never the number. Elevation, lit edges, tinted ramps, springs and scale contrast all belong to containers, chrome and type. The moment a technique touches a mark whose length, position or count carries a quantity, it becomes a second channel competing with the first — and the reader has no way to know which one to believe.
