## Store contract (DG-190)
Module defines `@dataclass(frozen=True) SnapshotBundle` with `artifacts: dict[str, bytes]`, `ranks: dict`, `comparison: dict`.
Functions:
- `save_snapshot(root: Path, bundle: SnapshotBundle, *, captured_at: datetime, code_sha: str) -> dict`: returns `{created: bool, snapshot: receipt}`.
- `list_snapshots(root: Path) -> list[dict]`: newest first, receipts only. Missing archive returns empty, no directory creation. Invalid/corrupt existing records raise, never silently disappear.
- `read_snapshot(root: Path, snapshot_id: str) -> dict`: validated `{snapshot: receipt, ranks: dict, comparison: dict}`.
Expose `WorkspaceSnapshotError(ValueError)` for corruption, validation and unsafe paths. Missing named snapshot may raise FileNotFoundError.

Immutable per-content snapshot directories identified by lowercase 64-char sha256. ID depends on schema version and all raw/derived content, excludes save timestamp/code_sha so recapture is idempotent. Metadata stores first saved time and capture code SHA. Write a complete temp directory under archive root and publish atomically without replacing an existing archive; clean own incomplete temp output on errors. Same-content concurrent saves must converge, differing snapshots coexist. Validate existing bytes against their archived manifest on list/read/re-save. Refuse malformed source/payload identity, booleans as numeric counts, non-finite JSON, duplicate player IDs and inconsistencies rather than inventing counts. Archive paths must be private real directories: reject symlink root/ancestors and path escapes. Never touch existing shared capture databases.

Receipt shape (exact API/frontend contract):
```
{snapshot_id: string, saved_at: ISO UTC timestamp, forecast_date: YYYY-MM-DD,
 market_as_of: string, ownership_as_of: string, years: number[],
 source: {report_run,report_sha256,market_sha256,league_sha256,catalog_run,catalog_content_sha256},
 counts: {model,market,paired,roster,available,available_with_forecasts,available_without_forecasts,starting_estimates},
 capture_code_sha: string, evaluation_status: 'ungraded'}
```
All source fields are strings. Count available only comparison.available population default. With forecasts means finite now AND future totals; retain missing/null and starting estimates unchanged. Full original populations and raw terms remain archived, including excluded/unranked rows; the counts are a readable summary. Dates must be valid and source dates cannot be later than saved_at. No backdating capture time to forecast_date. Zero is distinct from missing. Unknown code identity is literally `unknown`, never a model version.
CLI required explicit `--manifest`, `--catalog`, `--catalog-companion`, `--archive-root`; UTC clock at execution, git HEAD read-only code identity only for a clean source tree (otherwise `unknown`, never falsely claim HEAD contains dirty code), JSON receipt stdout, nonzero on refusal. No env defaults that could write to production; no scheduler edits.
